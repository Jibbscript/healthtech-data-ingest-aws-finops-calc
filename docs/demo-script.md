# Five-Minute Demo Script

0:00 — State the goal: reliable health-data ingest with visible unit economics.

0:30 — Open `Throne Overview`; show request rate, p99 latency, and error budget.

1:15 — Open `Throne Pipeline Health`; explain SQS backpressure, DLQ depth, and inference p99.

2:00 — Run or describe a short load scenario; show captures/day and bytes/day moving.

3:00 — Open `Throne Live Cost Dashboard`; set DAU to 300, then 100000, and point to $/user/month.

4:00 — Explain the cost levers: tiering, compression, Fargate right-sizing, and Spot workers.

4:45 — Close with what is intentionally not real in the PoC: synthetic model, no real PHI, single-region dev environment.
